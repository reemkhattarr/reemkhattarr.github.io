# reemkhattarr.github.io

Source of my portfolio site: **https://reemkhattarr.github.io**

A single static page (HTML + CSS, no build step) hosted on GitHub Pages. Each project links to its own repository; live demos are being added as static pages.

To preview locally, open `index.html` in a browser, or run `python -m http.server` in this folder and visit http://localhost:8000.
