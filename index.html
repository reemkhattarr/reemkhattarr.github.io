F1 machine learning

Python, scikit-learn, FastF1, MLflow, FastAPI, GitHub Actions

A set of ML projects built on real Formula 1 timing data, sharing one data foundation that pulls every session (practice, qualifying, sprint, race) from the FastF1 API and keeps it up to date automatically.

Tire strategy. Predicts when a car should pit and which compound it should take, from the live race state, on the 2022–2025 ground-effect era. Two models work together: a calibrated pit-timing model and a compound model, with a track-temperature-aware rain check for wet stops. Evaluated with grouped cross-validation over whole races and a cost metric where a missed pit stop costs more than an unnecessary one.

Race engineer tools

Python, OpenCV, scikit-image, Gradio, pytest

Small utilities for a race engineer's day-to-day work. The first is the Circuit Map Cleaner: give it a circuit map with labels, grey secondary tracks and clutter on any background colour, and it returns a clean outline with the track in black and direction markers in red. It adapts to image scale and stroke width instead of relying on fixed thresholds, and runs as a command-line tool or a web app.

PCB text extractor

Python, OpenCV, PyMuPDF, Tesseract

Reads PCB schematic and layout PDFs and extracts component reference designators (R12, C4, U1…), including rotated text. It renders pages at high resolution, finds character candidates, matches them against templates and groups them into labels. Includes evaluation scripts that compare template matching with OCR.

Domain-adaptive semantic segmentation

PyTorch, DeepLabV2, PIDNet, STDC, PEM

Real-time segmentation models lose accuracy when the scenery changes. On the LoveDA satellite dataset (urban for training, rural for testing) we measured that drop and reduced it with adversarial training and DACS image mixing, comparing accuracy (mIoU) against speed, FLOPs and parameter count. Advanced Machine Learning course, Politecnico di Torino.

Text-guided 3D highlighting

PyTorch, CLIP, differentiable rendering

Experiments with 3D Highlighter, which uses CLIP to mark the part of a 3D mesh described by a text prompt, such as a hat on a candle or shoes on a horse. Notebooks reproduce the method and test it on new mesh and prompt combinations.

Computational intelligence

Python, NumPy, Jupyter

Symbolic regression with genetic programming: evolving formula trees with crossover, mutation and a complexity penalty to find simple, accurate equations for a dataset. Plus labs on set cover, the travelling salesman problem and the n-puzzle with path search.
